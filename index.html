Alur Setting Suhu

  1. Tekan tombol Menu
  2. Gunakan Plus/Minus untuk memilih "SET A/C WATER"
  3. Tekan Menu untuk masuk ke pengaturan suhu
  4. Gunakan Plus/Minus untuk mengatur suhu yang diinginkan
  5. Tekan Menu untuk menyimpan perubahan

Panduan Penggunaan

Modul ini dirancang untuk membantu tim Commissioning dalam troubleshooting chiller Daikin UAL ER Series secara cepat dan akurat.

1
Gunakan Search Bar

Ketik kode error (contoh: F6, 20, 25) atau kata kunci masalah (contoh: kompresor mati, tekanan tinggi, sensor rusak). Tabel error akan tersortir otomatis secara realtime.

2
Klik Baris Error

Klik salah satu baris di tabel untuk melihat detail: penyebab umum dan langkah penanganan yang disarankan.

3
Filter Berdasarkan Model

Gunakan dropdown model untuk mempersempit hasil pencarian jika diperlukan.

4
Cek Wiring Diagram

Buka tab Wiring Diagram. Paste base64 string dari gambar wiring asli untuk referensi pengkabelan di lapangan.

5
Wired Controller Reference

Tab Wired Controller berisi panduan tombol, mode operasi, dan parameter utama MC324/MC250.

6
Print / PDF

Klik tombol Print untuk menyimpan halaman sebagai PDF atau mencetaknya.

📖 Panduan Cepat

Selamat datang di Daikin UAL Chiller Troubleshooting Module!

Langkah Cepat:

  1. Ketik kode error atau kata kunci di search bar
  2. Tabel error akan tersortir otomatis realtime
  3. Klik baris error untuk melihat detail penanganan
  4. Gunakan tab Wiring Diagram untuk referensi pengkabelan
  5. Gunakan tab Wired Controller untuk panduan handset

Tips:

  • Pencarian mendukung bahasa Indonesia & Inggris
  • Klik Print untuk simpan sebagai PDF
